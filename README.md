# קלפי 26

דשבורד נתונים לבחירות לכנסת ה-26 (27 באוקטובר 2026): ממוצע סקרים, מחשבון קואליציות, תוצאות חמש מערכות הבחירות האחרונות עד רמת הקלפי, ומרכז ייעודי לחברה הערבית.

**הדמו:** `site/index.html` (פתיחה דרך שרת מקומי, ראו למטה).
**התוכנית:** [`docs/PLAN.md`](docs/PLAN.md).

## מה יש בפנים

| מדור | תוכן |
|---|---|
| תמונת מצב | ממוצע סקרים לפי רשימה, התפלגות מנדטי הגושים מסימולציה, הכנסת לפי הממוצע, מעקב אחוז החסימה |
| סקרים | מגמות לפי רשימה וגוש, הטיית סוקרים לכל סוקר, כל הסקרים עם קישור לקובץ הדיווח הרשמי לוועדת הבחירות |
| מחשבון קואליציות | 120 מושבים, הרכבים מוכנים, מחוון השתתפות ערבית ותזוזה בין גושים |
| החברה הערבית | השתתפות לפי מגזר 2019–2022, מנדטי הרשימות הערביות, 10 אזורים, מעברי קולות, ערים מעורבות, דרוזים, סקרי 2026 |
| תוצאות ומפה | תוצאה ארצית רשמית, מפת 1,200 יישובים, דף יישוב, טבלת קלפיות |
| פילוח מגזרי | השתתפות והצבעה לפי 16 קבוצות, מקור הקולות של כל רשימה, מעמד חברתי-כלכלי |
| סקרים מול תוצאות | 54 הסקרים האחרונים לפני כל מערכת מול התוצאה, דיוק לפי סוקר |
| שיטה ומקורות | בדיקות תקינות, מקורות, הגדרות ומגבלות |

## הנתונים

- **תוצאות 2019–2022:** קובצי התוצאות לפי קלפי של ועדת הבחירות המרכזית (`media2X.bechirot.gov.il/files/expb.csv`). סכום כל רשימה זהה לטבלה הארצית הרשמית.
- **סקרי 2026:** 43 סקרים ייחודיים שפורסמו מאז סגירת הרשימות, חלקם מקושרים לקובץ הדיווח שמפרסמת ועדת הבחירות.
- **הלמ״ס:** גבולות יישובים 2022 ומדד חברתי-כלכלי 2021.

פירוט מלא: [`docs/DATA_SOURCES.md`](docs/DATA_SOURCES.md). שיטות: [`docs/METHODOLOGY.md`](docs/METHODOLOGY.md).

## הרצה

```bash
./run_pipeline.sh                        # הורדה, בנייה ובדיקות (Python 3, numpy, node)
python3 -m http.server 8000 --directory site
# http://localhost:8000
```

`run_pipeline.sh` מוריד את קובצי הוועדה ישירות כשהאתר זמין, ואם לא, משתמש בעותק ציבורי שנבדק מול טביעות SHA-256. הבנייה דטרמיניסטית.

## מבנה

```
pipeline/            צנרת הנתונים (Python)
  fetch_sources.py   הורדה ותיעוד מקורות
  build_data.py      תוצאות, מגזרים, יישובים, קלפיות, מעברי קולות
  bader_ofer.py      חלוקת מנדטים
  build_polls.py     סקרי 2026
  build_final_polls.py  סקרים אחרונים 2019–2022
  build_site.py      איחוד הדשבורד לקובץ אחד
  registry.py        רשימות, משפחות, גושים, מגזרים
  reference/         נתוני ייחוס (יישובים ערביים ודרוזיים, סקרים היסטוריים)
site/
  src/               קוד הדשבורד (HTML, CSS, JS)
  data/              קובצי הנתונים שהדשבורד טוען
  index.html         הדשבורד הבנוי
docs/                תוכנית, מתודולוגיה, מקורות
```
