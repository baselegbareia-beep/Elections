# קלפי 26

דשבורד נתונים לבחירות לכנסת ה-26 (27 באוקטובר 2026): ממוצע סקרים, מחשבון קואליציות, תוצאות חמש מערכות הבחירות האחרונות עד רמת הקלפי, ומרכז ייעודי לחברה הערבית.

**הדמו:** `site/index.html` (פתיחה דרך שרת מקומי, ראו למטה).
**התוכנית:** [`docs/PLAN.md`](docs/PLAN.md).

## הנתונים

- **תוצאות 2019–2022:** קובצי התוצאות לפי קלפי של ועדת הבחירות המרכזית (`media2X.bechirot.gov.il/files/expb.csv`), נשמרים ב-`data/official/` (2019 ב׳–2022). סכום כל רשימה זהה לטבלה הארצית הרשמית.
- **סקרי 2026:** הסקרים שפורסמו מאז סגירת הרשימות (46 סקרים ייחודיים נכון ל-10.10.2026; העדכון היומי מוסיף את החדשים עד 23.10), חלקם מקושרים לקובץ הדיווח שמפרסמת ועדת הבחירות.
- **הלמ״ס:** גבולות יישובים 2022 ומדד חברתי-כלכלי 2021.

פירוט מלא: [`docs/DATA_SOURCES.md`](docs/DATA_SOURCES.md). שיטות: [`docs/METHODOLOGY.md`](docs/METHODOLOGY.md).

## הרצה

```bash
./run_pipeline.sh                        # הורדה, בנייה ובדיקות (Python 3, numpy)
python3 -m http.server 8000 --directory site
# http://localhost:8000
```

`run_pipeline.sh` מנסה להוריד את קובצי הוועדה, אבל הבנייה משתמשת קודם בעותקים הרשמיים השמורים ב-`data/official/` (עם טביעות SHA-256 ב-`fetch_log.json`), ורק בלעדיהם בהורדה טרייה או בעותק הציבורי. הבנייה דטרמיניסטית.

**אירוח:** GitHub Pages במצב Deploy from a branch (`main`, שורש): `index.html` שבשורש מפנה ל-`site/`. פיד יום הבחירות (`.github/workflows/live.yml`) מפרסם את הנתונים החיים ל-`site/live/` ב-`main` ומבקש בנייה של האתר, לכל היותר פעם ב-8 דקות (התוצאות הראשונות והמדגמים הראשונים מיד); עדכון סקרים יומי (`.github/workflows/daily.yml`) רץ עד תחילת איסור פרסום הסקרים (24.10), כמו כל workflow מתוזמן רק מהענף `main`; טבלת הסקרים של הצד השלישי נקראת כנתונים בלבד (שום קוד שלה לא רץ), ב-job בלי הרשאות כתיבה, ונבדקת לפני שהיא נכנסת ל-`main`. חיפוש קובצי הוועדה של 2026 (`.github/workflows/discover.yml`) מדווח לענף `ops-reports`. נוהל יום הבחירות, התרגול, הגיבוי ממחשב בישראל ורשימת המפעיל: [`docs/ELECTION_DAY.md`](docs/ELECTION_DAY.md). בדיקת עשן של הפיד: `python3 pipeline/test_live.py`.

## מבנה

```
pipeline/            צנרת הנתונים (Python)
  fetch_sources.py   הורדה ותיעוד מקורות
  build_data.py      תוצאות, מגזרים, יישובים, קלפיות, מעברי קולות
  bader_ofer.py      חלוקת מנדטים
  build_polls.py     סקרי 2026
  build_final_polls.py  סקרים אחרונים 2019–2022
  build_site.py      איחוד הדשבורד לקובץ אחד
  build_turnout.py   סדרות ההשתתפות לפי שעה (2013–2022)
  live_model.py      תחזית ליל הבחירות מספירה חלקית, ובדיקה לאחור
  build_replay.py    שחזור לילות הבחירות 2021 (סדר אמיתי) ו-2022 (סדר מדומה) להדגמה, ובדיקות לאחור
  live_fetch.py      משיכת נתוני יום הבחירות (ועדת הבחירות) לקובצי live/
  test_live.py       בדיקת עשן של הפיד (ריצה יבשה, קבצים פגומים, שער 22:00, קלטים, השתתפות לפי קלפי ומדור החברה הערבית, תרגול, פרסום, קצב, workflows)
  live_config.json   כתובות ופרמטרים ליום הבחירות
  registry.py        רשימות, משפחות, גושים, מגזרים
  reference/         נתוני ייחוס (יישובים ערביים ודרוזיים, סקרים היסטוריים)
site/
  src/               קוד הדשבורד (HTML, CSS, JS)
  data/              קובצי הנתונים שהדשבורד טוען
  live/              הנתונים החיים של יום הבחירות (כותב אותם רק הפיד)
  index.html         הדשבורד הבנוי
data/official/       קובצי הקלפיות הרשמיים של הוועדה (2019 ב׳–2022) ו-SHA-256
live_input/          קלט ידני ביום הבחירות (שיעור הצבעה ארצי, מדגמים)
.github/workflows/   פיד יום הבחירות, עדכון סקרים יומי, חיפוש קובצי הוועדה (discover.yml), בדיקת הנתונים הרשמיים, בדיקת גישה לוועדה, פרסום דרך Actions (גיבוי)
docs/                תוכנית, מתודולוגיה, מקורות, נוהל יום הבחירות
```
