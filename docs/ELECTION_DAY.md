# יום הבחירות: נוהל הפעלה

מסמך זה מתאר את ההכנות ואת ההפעלה של לשונית "יום הבחירות" ב-27 באוקטובר 2026.

## איך זה עובד

- **הסקריפט:** `pipeline/live_fetch.py` מוריד את קובץ התוצאות הרשמי של ועדת הבחירות, `https://media26.bechirot.gov.il/files/expb.csv`, כל דקה.
- **מה הוא מחשב:** סכומים לכל יישוב, ותחזית לסיום הספירה (`pipeline/live_model.py`). התחזית מבוססת על בסיס 2022 ועל ממוצע הסקרים כנקודת מוצא.
- **מה הוא כותב:** הקבצים נכתבים לתיקייה `live/`: `results.json`, `turnout.json`, `status.json`, `history.json` ו-`exit_polls.json`.
- **מי מריץ ואיפה זה מתפרסם:** ה-workflow `.github/workflows/live.yml` מריץ את הסקריפט בשרתי GitHub ומעלה את `live/` לענף `gh-pages`, ליד הדף.
- **מה הדף עושה:** כשקיים `live/status.json` עם נתונים, הדף עובר ממצב "הדגמה" (ליל הבחירות 2022) למצב "חי", ומתעדכן כל דקה.

שרתי GitHub (Azure, ארה״ב) מגיעים ל-media2X.bechirot.gov.il. נבדק ב-9.10.2026: קובצי 2022 הורדו בהצלחה. קובצי 2026 החזירו 404, כי הוועדה ממלאת אותם בליל הבחירות.

## הכנות (עד 25.10)

1. **מיזוג ל-main.** למזג את ה-PR לענף `main`. הפעלות מתוזמנות (cron) של GitHub רצות רק מהענף הראשי.
2. **הפעלת GitHub Pages.** ב-Settings → Pages → Build and deployment: לבחור Source: Deploy from a branch, Branch: `gh-pages`, תיקייה `/ (root)`.
   - Pages לא זמין למאגר פרטי בחשבון חינמי. צריך מאגר ציבורי או חשבון GitHub Pro/Team.
   - האתר עצמו ציבורי תמיד, גם כשהמאגר פרטי (חוץ מ-Enterprise).
3. **גודל פנקס הבוחרים.** ב-`pipeline/live_config.json`, לעדכן את `eligible` למספר בעלי זכות הבחירה הרשמי שהוועדה פרסמה.
4. **תרגול.** ב-Actions → "Election day live feed" → Run workflow: לסמן `drill`, ולהגדיר `minutes` = 15.
   - התרגול מריץ את קובץ 2022 הרשמי דרך כל המערכת, והדף מסמן אותו "תרגול".
   - בסוף התרגול צריך למחוק את `live/results.json` מענף `gh-pages`, או להריץ את "Publish site" מחדש.
5. **נתוני השתתפות לפי קלפי.** אם הוועדה מפרסמת כתובת לנתוני ההשתתפות לפי קלפי (החלטת היו״ר מ-16.8.2026), יש לרשום אותה ב-`station_turnout_url`.

## ביום הבחירות

| שעה | פעולה |
|---|---|
| 06:30 | Actions → "Election day live feed" → Run workflow (גיבוי להפעלה המתוזמנת, שעלולה להתעכב) |
| 10:00, 12:00 … 22:00 | כשהוועדה מודיעה על שיעור ההצבעה הארצי (בדרך כלל 45–65 דקות אחרי השעה העגולה), להוסיף אותו ל-`live_input/turnout.json`, למשל `{"national": {"10:00": 15.2}}` |
| במהלך היום | נתונים ממפלגות או מגופי מחקר: להוסיף ל-`claims` באותו קובץ, עם מקור ושעה. הם יוצגו בנפרד כלא רשמיים |
| 22:00 | המדגמים של הערוצים: להוסיף ל-`live_input/exit_polls.json`. הקובץ מתפרסם רק אחרי 22:00 |
| 22:00 ואילך | התוצאות נמשכות אוטומטית. לבדוק ב-`live/status.json` ש-`results_state` הוא `ok` |

את קובצי `live_input/` עורכים ישירות ב-GitHub (סמל העיפרון), בענף שממנו ה-workflow רץ. כל ריצה מושכת אותם מחדש.

## כללים

- **סקרים:** מסוף יום שישי, 23.10, אסור לפרסם סקרים חדשים. ממוצע הסקרים בדף קפוא מאז.
- **מדגמים ותחזיות:** מדגמים ותחזיות לפני 22:00 אסורים. הסקריפט לא מפרסם את `exit_polls.json` לפני 22:00, והדף אינו מתרגם שיעורי הצבעה למנדטים לפני 22:00.
- **מקורות:** נתוני ועדת הבחירות מוצגים כרשמיים. כל מקור אחר מסומן כלא רשמי.

## אם שרתי GitHub חסומים

ב-9.10.2026 שרת הקבצים של 2026 (`media26`, דרך CloudFront) החזיר 404 לשרתי GitHub. לפי דיווח של צד שלישי, אותו שרת עונה לרשתות אחרות. ייתכן שהקבצים עוד לא הועלו, וייתכן שכתובות הענן של GitHub חסומות. לכן מכינים מראש מחשב בישראל, באחת משתי דרכים:

1. **Runner עצמי (מומלץ):** ב-Settings → Actions → Runners → New self-hosted runner, מתקינים את ה-runner על מחשב שיישאר דלוק בליל הבחירות. ביום הבחירות מריצים את "Election day live feed" עם `runner` = `self-hosted`. זה אותו תהליך בדיוק, על חיבור ישראלי.
2. **סקריפט ממחשב נייד:**

```bash
git clone <המאגר> && cd Elections && git checkout <הענף>
pip install numpy
python3 pipeline/live_fetch.py --out live --loop 60 --publish
```

הסקריפט מושך כל דקה ודוחף את `live/*.json` לענף `gh-pages` (דרך תיקיית עבודה `.live-pages`). צריך הרשאת push למאגר. כדי לא לדחוס את אותם קבצים משני מקומות, צריך לעצור את ההרצה ב-GitHub כשמפעילים את המחשב.

את הבדיקה כדאי לחזור עליה מהמחשב שנבחר כבר עכשיו: `curl -I https://media26.bechirot.gov.il/files/expc.csv` צריך להחזיר 200.

## בדיקות שהסקריפט מבצע

- **קבצים שאינם נתונים:** דף HTML במקום קובץ CSV (תחזוקה או חסימה) נדחה.
- **שורות בלתי אפשריות:** שורה עם יותר מצביעים מבעלי זכות בחירה נזרקת, ומספר השורות שנזרקו נרשם.
- **רשימות לא מוכרות:** אותיות שאינן ברשימה הידועה מסוכמות ל"אחרות" ונרשמות ב-`checks.unknown_lists`.
- **תיעוד:** לכל קובץ שהתקבל נשמר SHA-256.
